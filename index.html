Retrait sans attente

Consignes avec code

L’objectif : permettre aux clients de récupérer leur commande sans encombrer le magasin, à la manière d’un retrait sécurisé par code.

▤

Le parcours envisagé

1. Le client passe commande.

2. Le commerçant prépare le colis.

3. Un code unique est généré par un système sécurisé.

4. Le client récupère son colis dans une consigne compatible.

Prototype — pas opérationnel

Ce qu’il faudra intégrer

Un fournisseur de consignes compatibles, une génération de codes sécurisée, une gestion des ouvertures et un suivi des retraits.

Aucun code de retrait réel n’est généré par cette démonstration.
